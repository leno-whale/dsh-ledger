## 3. 剩下的结构性缺口：**「改」这个数是自证的**

现在 `改N` 的算法（`store.js:421-428`）：从 manifest 里取 `create|edit|(backup && imported)` 的去重路径。

问题不在实现，在**数据来源**：manifest 是插件自己写的。所以它永远只能回答「插件记到了什么」，回答不了「实际改了什么」。
换个说法：**账本自己当证人**。这跟我今天栽的那次是同一个形状——「只记做了什么，不记没做」。

现场证据（刚跑的，`C:\Users\HUAWEI\.dsh\whale-work\ledger-gap.mjs`）：

```
git 改了但没备份的已有文件：2
   x 接口/记录.md
   x 接口/记录-索引.md
```

`ledger_today` 现在输出 `改7 备13（含13导入）`，**读起来像「7 个都备好了」**，但那 2 个不在任何账上。装上之后，这类「改了没备份」会永久隐形——而它恰恰是账房存在的头号理由。

### 补法（两步，第二步可缓）

**第一步（3 行，立刻做）**：让「全部来自导入」这件事显形。

```diff
--- plugin/lib/tools.js    (ledger_today 首行拼接处)
-    `改${c.edits} 备${c.backups}${c.imported ? `（含${c.imported}导入）` : ''}`
+    `改${c.edits} 备${c.backups}${c.imported ? `（含${c.imported}导入${c.imported === c.backups ? '，本插件今日未拦到写操作' : ''}）` : ''}`
```

**第二步（真解，M2 再做）**：`改` 换成独立来源。

```js
// plugin/lib/git.js（新建）
import { execSync } from 'node:child_process';
import fs from 'node:fs';

// 返回今天动过的「已有」文件绝对路径（新建文件不算）
export function changedSince(repos, sinceISO, dateInZone) {
  const out = [];
  for (const repo of repos) {
    if (!fs.existsSync(repo)) continue;
    let s = '';
    try {
      s = execSync('git -c core.quotepath=false status --porcelain', { cwd: repo, encoding: 'utf8' });
    } catch { continue; }
    for (const line of s.split(/\r?\n/)) {
      if (!line.trim() || line.startsWith('??')) continue;
      out.push(repo + '/' + line.slice(3).trim().replace(/^"|"$/g, ''));
    }
    let l = '';
    try {
      l = execSync(
        `git -c core.quotepath=false log --since=${sinceISO} --name-only --pretty=format:`,
        { cwd: repo, encoding: 'utf8' },
      );
    } catch { continue; }
    for (const p of l.split(/\r?\n/)) {
      if (p.trim()) out.push(repo + '/' + p.trim());
    }
  }
  return [...new Set(out)];
}

// 改了但今天没有备份（含导入）的
export function unbacked(changed, manifestPaths) {
  const norm = (p) => p.replace(/\\/g, '/').toLowerCase();
  const have = new Set(manifestPaths.map(norm));
  return changed.filter((p) => {
    const n = norm(p);
    return ![...have].some((h) => n === h || n.endsWith(h.slice(h.lastIndexOf('/'))));
  });
}
```

`ledger_today` 里加一段 `未备份${k}`（k > 0 时列前 3 个名字），配置加 `watchRepos: ["F:/agent expore/接口", "F:/agent expore/本子游戏"]`（缺省空数组＝功能关闭，不强制）。
