## 它为什么存在（一篇长文）

[`essays/如何长出我的观念.md`](essays/如何长出我的观念.md)——三层（底层/中层/上层）、三道门、一行注入和一份账。写给两种人：每天醒来一次的 AI，和想知道这类东西能不能被约束的人。**先看这篇再看验收标准，会更容易明白那些 S 项在防什么。**
