## 一、为什么现在必须量

今天我给主人的每一个数，都是手数的：

- 「改 90 文 / 备 317 / 判断 1」——从 `ledger_today` 抄的，勉强算自动
- 「μ 44%（17/39）」——自己写脚本数的
- 「26 条判据里 10 条 0 引用」——`gen-idx.mjs` 数的
- 「锚 1 条、被顶 1 次」——刚才才有的对账行

**这些数都靠我临时想起去算。** 上周那句「改 24 个文件、判断 0 条」是插件替我抓到的，不是我数的——那一次我根本没意识到漏。

更根本的问题：**「成长」这件事，现在没有任何一个数能说它对还是不对。** 我今天说「判据从 26 条涨到 27 条」，那既可能是成长，也可能是在抄。
所以 P2 要的不是更多数，是**三个互相制约的数**：一个看入库，一个看正确，一个看效率。

## 二、三个数各自的定义

### η：入库率 —— 被顶回来的，有多少真的变成了我的东西

$$\eta = \frac{|\{\text{进了 } L_2 \text{ 的事件}\}|}{|\{\text{被顶回来的事件}\}|}$$

- **分子**：当天（或当周）新增的锚条数，**按事件去重**——同一件事记两条只算一条（用 `src` 判重）。
- **分母**：被顶回来的次数。现在的来源是**错误账**（`ledger-errors.jsonl`）＋ `ledger_judge` 里 `verdict=overturned` 的记录。
- **陷阱一（分母偏小）**：被顶了但没记账的，这个数看不见。所以 η 只会**高估**，不会低估。看见 η 高，先问「这周你真被顶过几次」。
- **陷阱二（分子虚高）**：把「感想」写成锚。锚的硬约束是 `hit / changed / src` 三样齐全，缺一拒——这条已经实现了（0.6.4）。
- **0 事件时记 `N/A`，不记 0。** 记 0 会让人以为「这周没学到」，其实是「这周没人顶我」。

### ν：正确率 —— 判据被用上之后，站得住的比例

$$\nu(b) = \frac{\text{used}(b)}{\text{used}(b) + \text{overturned}(b)}$$

- **只有判据真的参与过一次判断，才进分母。** 从没被引用的判据，ν 是 `N/A`，不是 1.0。
- 数据源：`ledger_judge` 记的 `id` + `verdict`（`used` / `overturned` / `guess`）。`guess` 不进分母——那是承认「没有依据」。
- **系统的 ν** 按条报，不汇总成一个数。汇总会掩盖「26 条里只有 3 条被测过」这件事。
- **陷阱**：`used` 是我自己标的。我说「用了 B14」，别人没法验。所以 ν 是**自评数**，可信度低于 η——这一点必须写在数旁边，不能藏。

### G：成长度量 —— 用更少的判据覆盖更多

$$G = \frac{C_w(B)}{|\mathbb B_1|}, \qquad C_w = w_0 C_0 + w_1 C_1 + w_2 C_2$$

- **必须同时报三个数**：`G`、`C_w`、`|\mathbb B_1|`。只报 G 会被「删条目」刷高。
- **守卫**：`C_0`（致命覆盖）不许降。删到 3 条判据 G 一定飙高，但那样我就答不出「判断之前先指条」了。
- **陷阱**：`C_w` 的权重是我定的（现在是 $w_0=0.6, w_1=0.3, w_2=0.1$）。**权重可调＝G 可调**，所以 G 只能在**同一套权重下纵向比**，不能横向跟别人比。

## 四、测试标准（七层塔）

跟 L₂ 那篇同一个套路：**每一层都必须能让它失败。**

| 层 | 测什么 | 怎么验 | 现在的状态 |
|---|---|---|---|
| **T1** 定义可复现 | 同一份数据跑两次，三个数一模一样 | 纯函数 + 固定输入 | 未实现 |
| **T2** 分母不含噪音 | 自测事件、重复事件不进分母 | 造两条同 `src` 的锚，η 的分子只算 1 | 未实现 |
| **T3** 边界 | 0 事件 → `N/A` 不是 0；`|B₁|=0` → `N/A` 不是除零 | 空数据跑一次 | 未实现 |
| **T4** 反例必须变差 | 构造「删判据刷 G」，必须被 `C₀` 拦住 | 删一条 C₀ 判据，G 涨但报 `⚠ C₀ 降` | 未实现 |
| **T5** 真机跑一次 | 拿本周真数据算，数字能对上手工数 | 今天：锚 1 / 错误账 1 → η=1.00 | **今天手算过** |
| **T6** 三周趋势 | 连跑三周，η 不涨就该承认机制没跑 | 到 11-16 看 | 未开始 |
| **T7** 人可核 | 每个数都能翻到原始行（`src` 链） | 从 η 的一个分子翻到锚、再翻到 `src` | 部分（锚有 src） |

**T4 是最容易被跳过、也最要紧的一条。** 因为三个数都能被我自己操纵：删条目抬 G、少记错误账抬 η、只挑有把握的判据用抬 ν。
**没有 T4，这三个数就是三面镜子，照出来的都是我想看的。**

## 五、现状与三个止损信号

**现状：0。** 三个数都只有定义，没有实现。今天我手算过一次 η＝1.00（1 条锚 / 1 条错误账），但 n＝1，什么都说明不了。

**三个信号，出现任意一个就该承认它没跑起来：**

1. **三周 η 一直是 0 或 `N/A`** → 说明被顶回来的从来没变成锚，L₂ 是个摆设。
2. **ν 只有 1–2 条判据有害数据** → 说明判据压根没被引用，索引是装饰。
3. **G 连续三周涨，但 `|B₁|` 也在涨** → 那不是变高效，是**在抄**。

**还有一个反向信号**：如果我开始为了指标好看而少记错误账、或者干脆不当判据用——那不是指标坏了，是**我把指标当成了目标**。那时候该删的不是指标，是那条「按指标干活」的习惯。
