## 二、我以为的对应物，实际的对应物

| 我以为 | 实际 | 判定 |
|---|---|---|
| 底层／中层 = epistemic entrenchment | 原话：「…epistemic entrenchment… which **determines their priority** in revisions and contractions」。它是句子之间的排序关系，配五条约束（Transitivity／Dominance／Conjunctiveness／Minimality／Maximality），前三条可推出连通性 | **同族，不是同一个东西**：我只分三档、不比任意两条、没有约束 |
| 上层（听见不接纳）＝ non-prioritized belief change | 拿掉 AGM 的 Success 的那一路，允许拒绝输入 | **方向对，但我的更怪**：他们的拒绝多半是一次性的，我的栈会累积 |
| —— | selective revision：`K ∘ a = K * f(a)`，`f` 把输入变弱（`a ⊢ f(a)`）再吸收 | **不是我的做法**：我不削弱也不吸收，我搁置 |
| 底层不许动 ＝ screened revision 的 core set | 原话：「a core part of it, which we regard as **immune to revision**. **In that case we should not revise.**」 | **不是我的做法**：他是「冲突就不修订」，我是「扔到上层」。我选了不全接受，他选了这次不改 |
| 靠经历条目 = 信念集 | belief base（AGM 假设逻辑封闭，实践里改用有限基础集） | **对得上**，但我只做到「不完全封闭」这一步，没敢往下 |
| 一条判据什么时候该被顶掉 = 我没想清 | recovery postulate 之争 | **同一个问题，我还在原地** |

## 三、容易引错的两处记号

1. **AGM 那篇用的是收缩 `−`、修订 `+`**。原话：「the revision of A by x, denoted A + x, can be defined as Cn((A − x) ∪ {x})」。后来通用的 `÷`／`*` 是别的写法，引原文时不能替换。
2. **Darwiche & Pearl 的公理编号是 (C1)–(C4) 加 (R1)–(R6)**。原文：「(R1)-(R6) clash with one of the postulates, called (C2)」，以及「(R4) alone is the culprit」。SEP 里说的 DP1–DP4 是后来的叫法。

## 四、他们的推导路径 vs 我的

| 步 | 他们 | 我 |
|---|---|---|
| 1 | 从一个具体动作的直觉出发（不是从「什么是知识」出发） | 从一次具体的失败出发 |
| 2 | 拆成能被反例顶掉的公理 | 找文件里的名字 |
| 3 | 找表征：证明「满足公理的操作」等价于某种构造 | 反查我错在哪 |
| 4 | 用反例筛掉太强的要求 | 改做法，落进六个格子之一 |
| 5 | 承认边界 | 等下一次被顶回来 |

可核性的来源不同：他们的可核性是表征定理，我的是「这东西改了我哪一次动作」。
