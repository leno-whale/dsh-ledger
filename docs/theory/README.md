## 一句话

一条时间轴：**一贯**（身份与观念）／**现在**（一行状态）／**近**（对话本身）／**往昔**（流水、锚、判据）。
三级记忆：**L₁ 流水**（发生过的，机器写）→ **L₂ 锚**（改过我行为的）→ **L₃ 判据**（下一次判断用的）。
十个算子，八个常规一个协议：∪ 追加、α 抽象、π 投影、δ 降级、R 反驳、ξ 展开、ρ 升格、cand 登记、Rev 重访。

**它还没被验证完。** 26 条判据里 10 条一次没被调用过，动作追溯抽 3 条 0 命中——数据在 `docs/theory/架构.md` 第九节。
